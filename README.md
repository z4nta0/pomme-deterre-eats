# Lake Pomme de Terre Eats

A guide to the places to eat around Lake Pomme de Terre in southwest
Missouri, from the lakeside towns to the marinas, live at
[pommedeterreeats.com](https://pommedeterreeats.com/).

The main site explains what the guide is, lists every eating place with a
search, and invites owners to add or update their entry. Each eating place
will also get a page of its own, styled like the business itself.

## Development

Built with React, React Router, TypeScript, and Vite.

```sh
npm install
npm run dev
```

- `npm run build` type checks and builds the site into `dist/`.
- `npm run lint` lints the whole project.
- `npm test` runs every test suite in Chromium, Firefox, and WebKit.
